# 绿电直连插图画法

本文件是“角度清单”：告诉你申报方案里有哪些图、每张图想说明什么、可以怎么画。它不是必须按序执行的流水线，可以只挑其中几张；`scripts/` 里的脚本是可运行的参考实现，能直接用就用，需要改样式或换思路时照着改即可。图号只是示例，按当地大纲重排。

## 一、通用画法

- 版心宽度：横排图宽约 16 cm（6.3 英寸），高 3 英寸左右；分辨率 220 dpi，导出 PNG，方便贴进 Word。
- 一张图只说明一件事，图题写清对象和统计口径（如“月平均负荷”“代表月日内平均出力”）。
- 同一语义同一颜色，全书统一（下表是建议约定，参考脚本中“典型日系统运行”按此配色，“月度电量平衡”另用了一套色板，改用时建议统一）：

  | 对象 | 颜色 |
  |---|---|
  | 负荷 | 蓝 |
  | 新能源出力（光伏 / 风电分开画时，光伏橙、风电紫） | 橙 |
  | 储能 | 绿（充电为正、放电为负） |
  | 弃电 | 黄 |
  | 外购电（公共电网） | 紫 |

- 单位统一为万 kW（功率）和万 kWh（电量），坐标轴写单位，数据标签保留 1～2 位小数。
- 柱状图从 0 起画；比选类图为了看清差异可以截断纵轴，此时必须在正文引用具体数值，不能只靠柱高说明差异。
- 中文字体优先微软雅黑，其次黑体；灰色网格线、无边框，图内不重复图题。
- 每张图在正文前后都要有引用，图号按章节顺序连续，文件名与图题一致（`图4.2-4_典型日系统运行.png`）。
- 想让数字可核对，作图时同步导出每张图的底层数据（参考实现的 `--data-xlsx`），报告数字和图取自同一份数据。

## 二、按类型的画法

### A. 位置类（第一章、第二章、第四章）

想说明：项目在哪，电源场址与负荷相距多远，周边有什么限制。

- 首选业主提供的奥维或卫星截图，在上面标出场址范围、负荷位置、拟建线路和比例尺、指北针。截图缺少坐标时，用 `geospatial-converter` 技能把 KML 面叠加到截图上，得到带范围的底图。
- 没有截图时画示意图：把 KML 场址范围画成半透明面，负荷用方块标注，虚线连接并标注“直线距离约 X km、线路长度约 Y km”，配比例尺和指北针。参考实现 `scripts/make_site_map.py`。
- 分层：第一章画“项目在区域中的位置”，第二章画“场址范围与地形、道路、限制性因素”，第四章画“场址分布与负荷”。三张不必各画新图，可用同一底图不同标注。
- 场址范围来自业主 KML 时，以它为准，面积、形心、距离都用它算出。

### B. 气候资源类（第二章）

想说明：场址的资源条件够不够、稳不稳。

- 逐月气温与降水：左右两个子图，左为气温折线（极端最高、月平均、极端最低），右为降水柱并在图题写年合计。
- 逐月太阳辐射：总辐射按直射、散射堆叠柱；同时算出太阳能资源丰富程度、稳定程度和直射比，等级判据见 GB/T 37526—2019。
- 风电项目改画：月平均风速、风速频率直方图、风向和风能玫瑰。脚本尚未实现，思路是用测风塔或再分析逐时数据分组统计。
- 数据来源：有测风塔、SolarGIS、Meteonorm 报告时优先用报告；没有时用 NASA POWER 多年气候统计（`scripts/fetch_nasa_power.py`），并在正文注明为公开再分析数据。
- 参考实现：`scripts/make_context_figures.py climate`。

### C. 负荷特性类（第三章）

想说明：负荷是稳定的还是波动的，峰谷差多大，能调多少。大纲通常要求年、月、日三种典型曲线。

| 图 | 角度 | 画法 |
|---|---|---|
| 全年逐日负荷 | 年内变化，检修停产在哪 | 日平均和日最大两条折线，加额定功率虚线；负荷全天恒定时只画一条 |
| 月平均负荷 | 季节差异 | 12 根柱，柱顶标数值 |
| 日平均负荷 | 日内峰谷 | 24 点折线，可与新能源日均出力同图，直接看错位 |
| 典型日负荷 | 夏季、冬季各一天 | 两条折线加额定功率线 |
| 负荷率区间分布 | 多少小时在低负荷 | 按负荷率分档统计小时数柱状图，停机单独一档 |

负荷可调节能力（可中断、可调节）没有专用图，用表格加工艺说明；如果负荷有明确调节范围，可以在典型日图里加最小、最大负荷率的带状区间。

### D. 新能源出力特性类（第四章 4.1）

想说明：出力有什么规律，与负荷错位在哪里，为什么需要储能。大纲要求从出力频率、典型日、典型月、全年四个方面讲。

| 图 | 角度 | 画法 |
|---|---|---|
| 各月发电量 | 全年电量分布 | 12 根柱；风光并存时叠加或并列 |
| 全年逐日发电量 | 全年波动，连续低出力日 | 逐日折线 |
| 日内平均出力 | 一天中什么时候有电 | 24 点折线，风光分别画 |
| 各月日内平均出力 | 季节变化 | 12 月各一条曲线（小图阵列或渐变色叠加） |
| 代表月日内平均出力 | 简化版 | 选 1、4、7、10 月 |
| 典型日出力 | 大出力日、小出力日 | 夏季大出力日、冬季大出力日、夏季小出力日各一条；典型日默认取 6 月、12 月发电量最大和最小的日子，可指定 |
| 出力频率分布 | 大部分时间出力在什么区间 | 出力占装机容量的比例分档，统计小时数；光伏只统计有出力时段 |
| 年出力持续曲线 | 满发多少小时 | 8760 h 出力从大到小排列 |

口径提醒：逐时出力若是直流侧口径而报告写交流侧装机，比例会超过 100%；出力比例统一按同一侧容量计算，并在图注或正文说明。

### E. 平衡运行类（第四章 4.2）

想说明：源、储、荷在一年里怎么平衡，哪里弃电，哪里外购。这是全书最有说服力的一组图。

| 图 | 角度 | 画法 |
|---|---|---|
| 全年 8760 h 运行 | 一年总貌，负荷阶梯与出力波动的对比 | 负荷、新能源出力全年曲线（并网型可叠外购电），叠最大运行功率虚线 |
| 月度电量平衡 | 每月电量去向与来源 | 左右两栏堆叠柱：左栏“新能源电量去向”（直供负荷、储能充电、弃电），右栏“负荷电量来源”（新能源直供、储能放电、外购电） |
| 日平均系统运行 | 平均意义上的一天 | 24 点折线加储能、弃电、外购柱 |
| 典型日系统运行 | 具体某天怎么调度 | 折线（新能源出力、负荷）加柱（储能充放、弃电、外购），大出力日与小出力日并排两栏 |

这一组图的符号约定要在全书统一：储能充电为正、放电为负，弃电和外购电为正柱。图与文字的数字（自发自用比例、弃电率、外购电量）必须来自同一份逐时数据。

### F. 规模比选类（第四章 4.3）

想说明：为什么是这个规模和配置，而不是更大或更小。

- 电源规模比选：横轴为某种电源装机（固定另一电源和储能配置），三个小图并排——绿电占总用电量（叠政策目标线，如 50%）、弃电率或利用率、综合电价；推荐方案用橙色圆点标出并标数值。
- 储能配置比选：横轴为储能功率配比，按储能时长分组柱状，比较利用率、反推电价，在推荐方案上标“推荐”。
- 方案之间除比选变量外条件保持一致；比选表整理成 `schemes.csv`（字段见下）。
- 结论要能落到指标上：满足政策指标的最小规模、电价最低点、弃电率拐点，写进正文。

### G. 电力系统接线示意图（第五章）

想说明：电源、储能、负荷怎么连，物理分界点在哪，是否并网。

- 布局固定从左到右：电源（光伏、风电、储能）→ 电源侧升压站 → 直连专线 → 负荷侧变电站 → 负荷。
- 公共电网放在负荷侧变电站上方，用虚线连接，旁注“关口计量 / 防逆流 / 物理分界点”；离网型项目不画公共电网。
- 线上标电压等级和线路回数、长度（“220 kV 直连专线 1 回，约 70 km”）；各电源到升压站的集电线路标 35 kV 等。
- 框内写容量（“光伏 交流侧 10.028 万 kW”“储能 60 MW / 120 MWh”）；同类设备同色。
- 底部一句话说明运行方式（一体化调控平台统一调度，不向公共电网反送电）。
- 参考实现：`scripts/make_context_figures.py diagram`，输入 `params.json` 的 `diagram` 块。
- 正式电气主接线（含断路器、主变、母线接线）用 `diagram-creator` 技能输出可编辑的 Draw.io 文件，示意图和主接线图分开画，不混在一张里。

### H. 其他可以加的图

大纲没有硬性要求，但评审常喜欢看，按项目需要挑：

- 投产时序图：分期项目画甘特图，负荷分期与新能源分期同步对齐。
- 一体化调控平台架构图：设备层、通信层、平台层、调度接口四层框图（`diagram-creator`）。
- 电量流向图：用桑基图表示“发电 → 直供 / 储能 / 弃电”“外购 → 负荷”，一张图讲清自发自用比例。
- 源荷匹配热力图：横轴日、纵轴小时，颜色表示绿电占比，直观看出全年薄弱时段。
- 产业工艺流程图：第三章说明负荷用电环节时使用。
- 接入线路走廊图：第五章有多条线路或交叉跨越时使用。

## 三、参考实现

`scripts/` 里的脚本互相独立，都可以单独运行：

| 脚本 | 作用 | 输入 |
|---|---|---|
| `prepare_hourly.py` | 把测算表 xlsx 和 PVsyst CSV 整理成标准 8760 h 数据，并出指标摘要 | 测算表、PVsyst 逐时 CSV |
| `make_figures.py` | 第三、四章数据图（C、D、E、F 类） | `hourly.csv`、`params.json`，可选 `schemes.csv` |
| `make_context_figures.py` | 气候资源图（B 类）、接线示意图（G 类） | NASA POWER JSON、`params.json` |
| `make_site_map.py` | 场址位置示意图（A 类） | KML、负荷经纬度 |
| `fetch_nasa_power.py` | 下载 NASA POWER 场址气候统计 | 经纬度 |

常用命令：

```bash
# 数据图：默认全出，--only 只出指定图号，--data-xlsx 同步导出图的底层数据
python scripts/make_figures.py --hourly hourly.csv --params params.json --out 2-figures --data-xlsx 2-figures/图表数据.xlsx --only 4.2-4,4.3-1

# 气候图与接线图
python scripts/fetch_nasa_power.py --lat 44.77 --lon 89.93 --out NASA_POWER.json
python scripts/make_context_figures.py climate --nasa NASA_POWER.json --out 2-figures
python scripts/make_context_figures.py diagram --params params.json --out 2-figures

# 场址示意图
python scripts/make_site_map.py --kml 场址.ovkml --load 89.24,44.89 --line-km 70 --out 2-figures/图4.1-1_场址及负荷位置示意.png
```

参数模板见 [../resources/params.example.json](../resources/params.example.json)，`figures` 字段可以给图重新编号、改图题或关闭某张图。

### 标准逐时数据 `hourly.csv`

8760 行，功率单位万 kW（每小时值同时等于万 kWh）：

| 列 | 含义 |
|---|---|
| `time` | 时间戳（典型年，非闰年） |
| `pv` | 光伏送到项目侧的出力，无光伏为 0 |
| `wind` | 风电出力，无风电为 0 |
| `load` | 负荷用电 |
| `bat` | 储能功率，充电为正、放电为负 |
| `curt` | 弃电 |
| `grid` | 从公共电网外购的电，离网型为 0 |

### 比选方案 `schemes.csv`

每行一个方案，字段：`pv`、`wind`（装机，万 kW）、`bess_ratio`（储能功率配比，0.1 即 10%）、`bess_hours`（储能时长）、`util`（新能源利用率）、`gen_share`（自发自用占发电量）、`load_share`（自发自用占用电量）、`price`（反推电价）。缺哪一列，对应子图就自动不画。`params.json` 的 `schemes` 块里指定推荐方案和横轴变量。

## 四、出图检查

- 图里的负荷、装机、储能规模与 `params.json`、正文和大纲信息表一致。
- 图例、坐标轴单位、数据标签齐全，没有文字截断。
- 典型日、代表月在图题或正文中写明具体日期。
- 图中自发自用比例、弃电率等数字与正文指标一致；调整上游数据后重新出图，再回头改正文。
- 位置图上的比例尺、指北针、图例没有遗漏，业主底图注意涉密和授权。
