# 绿电直连申报方案大纲框架

各省对“绿电直连 / 新能源就近消纳”申报方案的章节要求不同，但内在逻辑一致：先证明负荷真实合规，再证明新能源与储能的规模合理，最后证明能建、能接、经济、安全。动笔前先取得项目所在省的正式编制大纲，本文件只帮助理解大纲背后要论证什么，并提供不同省份大纲的对照。

## 一、主线逻辑

```
负荷是真的、合规的        → 负荷情况分析
新能源出力什么样          → 出力特性分析
源荷怎么在内部平衡        → 调峰策略 + 8760 h 生产模拟
规模为什么是这个数        → 多方案比选
怎么建、怎么接            → 建设方案 + 电力系统接线
花多少钱、电价多少        → 投资估算与经济效益
出问题怎么兜底            → 安全风险 + 保障措施
```

## 二、政策硬指标

以下指标几乎每份省级文件都会出现，正文必须写明“计算值 vs 要求值”。具体数值以项目所在省的文件为准。

| 指标 | 国家口径（650 号、688 号） | 说明 |
|---|---|---|
| 自发自用电量占总可用发电量 | 不低于 60% | 由 8760 h 生产模拟得出 |
| 自发自用电量占总用电量 | 不低于 30%，2030 年前不低于 35% | 同上，反映绿电占比 |
| 上网电量占总可用发电量 | 原则上不超过 20% | 并网型项目；新疆等地要求不向电网反送电 |
| 接入电压等级 | 原则上不超过 220 kV | 220 kV 常需电力系统安全风险分析专项 |
| 直连线路长度 | 江西文件写“原则上不超过 50 公里” | 其他省份以当地文件为准 |
| 分类 | 并网型 / 离网型 | 决定接线图、防逆流和电网关口的画法 |

地方文件常见的额外要求：分期投产时新能源与负荷同步；配置一体化调控平台，实现源荷储“可观、可测、可调、可控”；承诺负荷不足或调峰能力下降时补足；关口计量点位置。

## 三、新疆大纲（九章，最完整的参考）

来源：新疆发改委《关于加快推进新疆新能源就近消纳有关事项的通知》附件 3。

| 章 | 节 | 要论证什么 | 常配图 |
|---|---|---|---|
| 一 项目概述 | 建设意义和必要性；地区社会经济现状；项目总体概况 | 电源、负荷、电网、接入的地点、规模、主体、调峰方案、新能源占比、时序、投资 | 项目位置示意图 |

| 七 安全风险分析 | — | 系统风险、用电安全、电能质量及具体技术措施 | 可不配图 |
| 八 环境影响及社会效益分析 | — | 环境影响与保护、节能减排、社会效益 | 可不配图 |

## 五、写作提示

- 大纲是硬约束：每一项要求都要在报告中有对应内容；用户给了参考报告时，沿用其小节结构和叫法，新增要求并入最接近的原有小节。
- 报告是给评审看的：写事实和论证，不写“经核对”“我方认为”这类内部过程表述，不挑业主或政策文件的毛病。
- 业主备案的规模、负荷配置和厂址优先，报告负责论证支撑，不推翻。
- 全书数字来自同一套逐时数据和同一张测算表：规模、电量、投资在第一、四、五、六、八章必须一致。
- 【待业主确认】只用于交付前需要业主补齐的事实。
