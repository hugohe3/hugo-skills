# PDF 转录与排版规范

## 保真原则

最终 Markdown 同时满足两项要求：

1. **内容忠实**：不概括、不润色、不合并具有独立法律或技术含义的句子，不擅自修正原文中的名称、编号和引用。
2. **结构可读**：去除分页造成的断行，恢复标题、段落、列表、条款、表格和公式，使内容脱离 PDF 版面后仍能正确阅读。

遇到疑似原文错误时，先按原文转录，在交付说明中单独指出。除非用户要求校订版，不要把判断悄悄写进正文。

## Markdown 结构

- 每篇文档通常只保留一个一级标题。
- 章使用二级标题，节使用三级标题；更细层级按项目约定继续下沉。
- 编号条款可写为 `**3.2.1** 条文内容`，保留原编号但避免为每条生成过深标题。
- 原文列表使用 Markdown 有序或无序列表；不要把连续正文误切成列表。
- 前言、附录、引用文件、用词说明和条文说明按原文独立成节。
- frontmatter 只在用户或目标项目要求时添加，字段名和日期格式服从目标项目。

## 文本

- 合并仅因换行或分页产生的断句。
- 保留原文的专用术语、助动词强度、标点含义和计量单位。
- 去除重复页眉、页脚、页码、水印和扫描软件标记，但保留属于正文的脚注、表注和图注。
- 不把目录页当成正文重复录入；目录本身是否保留服从用户要求或项目惯例。
- 英文缩写、变量和数字与中文之间的空格服从目标项目风格；不得因此改变编号或公式。

## 表格

优先使用 Markdown 表格，并逐项核对列标题、行标题和单元格归属。

- 跨页续表应合并为一张表，续表标题只保留一次；
- 合并单元格若能通过重复表头或分组列无损表达，可展开为普通单元格；
- Markdown 表格无法保留必要的多级表头或跨行关系时，使用 HTML 表格；
- 单元格中的空白、破折号、零和“不适用”含义不同，不得互换；
- 表名、单位行、注和资料性说明必须保留。

## 公式与符号

- 行内公式使用 `$...$`，独立公式使用 `$$...$$`，除非目标项目有不同约定；
- 使用标准 LaTeX 表达上下标、分式、根号、希腊字母、向量和矩阵；
- 公式编号按原文保留在公式之后；
- 变量释义和公式适用条件不能只留在图片中；
- 区分字母 `O` 与数字 `0`、字母 `l` 与数字 `1`、减号与连字符、乘号与字母 `x`。

## 图示与图片

只保留承载独立信息、无法被文本或表格完整替代的图：流程图、结构图、地图、曲线、示意图等。

- 图片放在目标项目规定的资产目录，并使用相对路径；
- 裁掉无关页边、页眉和水印，但不得裁掉图例、坐标轴、单位和注释；
- 图片前后保留原图题和必要说明；
- 纯文字截图、公式截图和普通数据表应转成可编辑内容，不应继续作为图片保存。

## 元数据与外部核实

封面可识别的信息包括题名、编号、发布机关、发布日期、实施日期、版次和出版信息。只录入原文实际提供的字段。

现行状态、替代关系、官方网页和下载来源属于外部核实信息，不得根据 PDF 年份猜测。需要这些字段时查询权威来源，并把引用放在对应事实附近。

## 覆盖检查

转录过程中维护简短的页码或章节覆盖记录。最终至少确认：

- 从第一页到最后一页均已分类为“已转录”“仅版式页”或“明确跳过”；
- 目录中的每个正文部分都能在 Markdown 中找到；
- 文中引用的表、图、公式和附录均存在，或已说明源文件本身缺失；
- 没有因跨页、双栏或浮动文本框导致阅读顺序错误。
