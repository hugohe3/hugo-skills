# 影印版与扫描 PDF 工作流

## 核心原则

影印 PDF 的最终内容由当前模型直接阅读页面图像后确定。传统 OCR 可以加速定位或提供候选字符，但不能替代视觉校核，特别是人名、编号、表格、公式和低清晰度字符。

## 页面准备

1. 获取总页数，确认页面方向、双页扫描、裁边和倾斜情况。
2. 以约 160-200 DPI 渲染全部页面，保证正文可读且文件规模可控。
3. 对人名表、密集表格、脚注、印章、公式或模糊文字制作 240-300 DPI 的局部裁图。
4. 不要用低清晰度整页截图猜测细小字符；先放大或重新渲染。

若页面旋转、颠倒或明显倾斜，先生成纠正后的临时图再识读，不修改原始 PDF。

## 分批识读

按连续页或自然章节分批，每批规模以能稳定保持编号和上下文为准。推荐顺序：

1. 封面、版权页、发布信息；
2. 前言、起草和审查人员；
3. 目录；
4. 正文各章；
5. 附录、引用文件和条文说明。

每批记录起止页和最后一个条款号。进入下一批时先对照上一批末尾，检查跨页句子、续表和连续编号。

## 高风险内容

以下内容必须放大复核，必要时用多个裁图或 OCR 结果交叉检查：

- 人名、机构名和生僻字；
- 标准号、文号、年份、公告号和日期；
- 表格中的小数、负号、单位和百分数；
- 上下标、希腊字母、矩阵、分式和公式编号；
- 页边处被装订、阴影或裁切遮挡的字符；
- 跨页表格的列对齐和续表关系。

仍不能确定时使用明确占位符并在交付说明中列出页码与上下文，不得选择“看起来最合理”的字符。

## 图文取舍

- 纯文字页面全部转录为文本；
- 公式转为 LaTeX；
- 参数表、清单和数据表转为 Markdown 或 HTML 表格；
- 签章、装饰性封面、重复水印通常不保留；
- 只有结构图、曲线、地图等独立图示需要裁出并作为资产引用。

## 完成检查

识读完成后按目录和总页数反向核对一次：

- 每页都有处理结论；
- 每章首条、末条和跨页条款连续；
- 每张表的行列数量与页面一致；
- 公式与变量说明成对出现；
- 姓名、编号、日期和关键数值已做第二次视觉检查。
